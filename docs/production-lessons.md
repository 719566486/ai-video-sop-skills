# 制作经验如何进入技能

| 历史问题类型 | 可迁移规则 | 本项目实现 |
|---|---|---|
| 平均分配画面导致旁白错配 | 逐句绑定叙事镜头 | 制作脚本与逐镜对白字段 |
| 单一慢推代替真实动作 | 主体动作和运镜分别验收 | action_prompt、camera_prompt、动态检查 |
| 人物换衣不换脸，配角衣服误换 | 参考角色分工；编辑锁定不变项 | 实体ID与参考角色、原始锚点 |
| 纹样变活物、银饰漂移 | 结构/图案属于不可变项 | 道具/服装设定＋风险区间审看 |
| 左手长成右手、交接错位 | 检查整条肩肘腕及接触过程 | 连续区间检查，而非起止帧检查 |
| 同图首尾导致无动作 | 稳定性与动作完成度分开 | 失败分支，不用推镜掩盖 |
| 过度约束后不断付费重试 | 重新设计可实现动作，先选可靠片段 | provider契约＋禁止自动付费重试 |
| 提交已收费但保存失败后重复提交 | 先保存原始回执，恢复原ID | reserve/record与UNKNOWN状态 |
| 跨任务余额变化误归账 | 逐任务回执，不用余额差代替 | actual与estimate分开保存 |
| 一两帧邻镜污染、动作尾段被裁掉 | 准确源入出点与最终帧核查 | 整数帧、范围绑定审看、导出检查 |
| BGM叠加、旁白弱、字幕过大 | 独立音轨、音乐避让、实际输出检查 | 混音/响度/SRT与听审分离 |
| 命令过长、中文路径、编码错误 | UTF-8文件、参数数组、ASCII中间名 | 标准库helper，避免JSON塞入命令行 |
| 覆盖旧版或日志 | 版本化输出、保留素材 | 已存在final拒绝覆盖、独立render目录 |
| 解码通过被当成艺术合格 | 技术/视觉/听审分别记录 | QA返回未执行视觉/听审，不伪认证 |

以上是匿名化的操作经验，不包含原作品人物资料、原图、未公开脚本或账单。某个客户的审美与字幕偏好不作为通用禁令。
